# Compatibility

Target:

- Built for LMMS 1.3 nightly according to the original theme notes.

Notes:

- `Nullfjord/` is the LMMS theme directory.
- UI assets live under `Nullfjord/assets/ui/`.
- Convention-based files such as the main icon and splash image now also live in `Nullfjord/`.
- This layout assumes LMMS accepts nested `resources:` paths such as `resources:assets/ui/gear.svg`.
