# Asset Index

Nullfjord keeps all LMMS runtime files inside `Nullfjord/`, with most UI artwork under `Nullfjord/assets/ui/`.

Main asset groups in `Nullfjord/assets/ui/`:

- `edit_*`: editor tools and actions
- `note_*`: note values and beat editor icons
- `project_*`: file/project actions
- `lcd_*`: LCD display variants
- `step*` and `stepper*`: beat buttons and steppers
- `sbarrow_*` and `arrow-*.svg`: scrollbar and control arrows
- `lfo_*`, `filter_*`, `wave_*`: synth and modulation artwork
- `track_*`, `mixer_*`, `automation_*`: arrangement and mixer assets

Files at `Nullfjord/` root are the convention-based LMMS assets such as the main theme icon, splash image, checker background, and assembled `style.css`.
